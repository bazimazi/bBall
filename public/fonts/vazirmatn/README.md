# Vazirmatn

Unmodified variable webfont from [Vazirmatn v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003).
The upstream `fonts/webfonts/Vazirmatn[wght].woff2` is bundled here as
`Vazirmatn-Variable.woff2`; it supports weights 100–900.
